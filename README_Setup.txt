HƯỚNG DẪN CÀI ĐẶT MÔI TRƯỜNG DỰ ÁN

1. Yêu cầu hệ thống:
   - JDK 17 hoặc cao hơn.
   - Apache Tomcat 9.0.
   - MySQL Server 8.0.

2. Các bước thực hiện:
   - Bước 1: Import file SQL trong thư mục database vào MySQL.
   - Bước 2: Mở dự án bằng Eclipse hoặc IntelliJ IDEA.
   - Bước 3: Cấu hình lại username/password database trong file DBConnection.java.
   - Bước 4: Run trên Server Tomcat và truy cập http://localhost:8080/project.
